# 🤖 AI Interview Coach

> **Your Personal AI-Powered Career Development Platform**

AI Interview Coach is an intelligent web application that helps job seekers prepare for interviews through AI-powered mock interviews, real-time evaluation, personalized career coaching, resume analysis, and performance insights.

Unlike traditional mock interview platforms, AI Interview Coach continuously learns from a candidate's interview history to provide personalized learning roadmaps, actionable career guidance, and adaptive interview preparation.

# 💻 Getting Started

## Clone Repository

```bash

```

## Frontend

```bash
cd client
npm install
npm start
```

## Backend

```bash
cd server
npm install
npm run dev
```
